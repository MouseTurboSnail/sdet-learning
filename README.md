Простой API на примере Linux-служб. Можно посмотреть, какие службы есть, узнать статус конкретной службы по имени, добавить новую, поменять ей статус или удалить.

Для примера взял ssh и NetworkManager. Имена и статусы лежат в обычном словаре Python. Когда меняю статус ssh через API, меняется запись в словаре. Сама служба в Linux продолжает работать как раньше.

Запуск

Из папки проекта, с активированным виртуальным окружением:
python -m pip install -r requirements.txt
python -m flask --app app run


В другом терминале можно посмотреть статус ssh:
curl http://127.0.0.1:5000/services/ssh


Сразу после запуска ответ будет running

Какие делал проверки:

Написал 17 тестов. Например, у ssh статус running. Пробую поменять его на пустую строку и жду 400. Потом ещё раз запрашиваю статус ssh и проверяю, что там по-прежнему running

Запуск всех тестов:

python -m pytest -q test_app.py


При каждом пуше эти же тесты запускаются в GitHub Actions

Что где лежит:
API = app.py 
Тесты = test_app.py

В hello.py = мои заметки, часть упражнений и прочее
